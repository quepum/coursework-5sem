\section{Цель и задачи работы}

\subsection{Цель}
Разработать численный метод оценки эффективности критериев согласия по Ходжесу--Леману.
Реализовать его в виде нового типа эксперимента фреймворка
\texttt{pysatl-\allowbreak{}experiment} с подменяемым этапом вычисления. Корректность метода
подтверждается сопоставлением численных оценок с аналитическими значениями для критериев,
для которых значения получены.

\subsection{Декомпозиция работы на задачи}

\begin{enumerate}
    \item \textbf{Подготовительная.} \done
    \begin{itemize}
      \item Согласовать тему, цель и план работы с руководителем; уточнить меру
            эффективности: бахадуровская эффективность заменена на эффективность по
            Ходжесу--Леману.
      \item Распределить работы в проекте: аналитические значения эффективности рассчитываются
            другим участником команды, численный метод и его интеграция во фреймворк выполняются
            в рамках курсовой; согласовать формат передачи эталонных значений.
      \item Создать репозиторий отчётности, подготовить аннотацию,
            цель, задачи и подборку литературы.
    \end{itemize}

    \item \textbf{Изучение метода.} \planned{5 семестр, спринт 1--2}
    \begin{itemize}
        \item Изучить определение эффективности по Ходжесу--Леману и условия её
              применимости.
        \item Обосновать вычислительную схему: оценка показателя скорости по наклону
              зависимости $\ln\bigl(1 - \pi_n(\theta)\bigr)$ от объёма выборки $n$.
        \item Определить необходимые величины (порог отвержения, мощность, объём выборки)
              и допущения при оценке вероятностей малых величин.
    \end{itemize}

    \item \textbf{Доработка фреймворка.} \planned{5 семестр, спринт 3--4}
    \begin{itemize}
      \item Составить перечень ограничений текущей архитектуры, мешающих новому типу
            эксперимента.
      \item Спроектировать подменяемый этап вычисления: численный и аналитический методы
            как взаимозаменяемые стратегии, выбор которых задаётся в конфигурации.
      \item Устранить их, не нарушая работу существующих типов экспериментов.
    \end{itemize}

    \item \textbf{Реализация эксперимента.} \planned{5 семестр, спринт 5--6}
    \begin{itemize}
        \item Реализовать воркер расчёта показателя скорости и эффективности.
        \item Реализовать стратегии численного и аналитического методов.
        \item Интегрировать запуск через CLI.
        \item Реализовать сохранение результатов и генерацию отчёта.
        \item Написать тесты и документацию.
    \end{itemize}

    \item \textbf{Проверка и эксперименты.} \planned{6 семестр}
    \begin{itemize}
        \item Сравнить численные оценки с аналитическими значениями.
        \item Оценить погрешность и сходимость оценок по объёму выборки и числу прогонов,
              построить доверительные интервалы.
        \item Провести итоговый расчёт для выбранного семейства распределений.
    \end{itemize}

    \item \textbf{Оформление результатов.} \planned{6 семестр}
\end{enumerate}

\paragraph{Что не входит в задачи.} Обзор литературы отдельной задачей не является: он
ведётся непрерывно и оформляется отдельным файлом.
Аналитический вывод формул для показателя скорости и расчёт эталонных значений
эффективности выполняет коллега по команде.
